# Product image credits

All product images in this folder are **AI-generated, original artwork** made for this portfolio
project. They are not photographs, they depict made-up products from a fictional shop, and they use
no real brands, logos or live animals for sale.

For each image this file lists the generation tool and the prompt used, so every picture can be
reproduced or replaced. Files live in `<category-slug>/<product-slug>-<n>.webp` (1200 x 1200) with a
`-600.webp` twin (600 x 600), produced by `pnpm images:process`.
